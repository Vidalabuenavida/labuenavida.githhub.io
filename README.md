# La Buena Vida Handtekeninggenerator – GitHub Pages

Deze versie gebruikt vaste afbeeldingsnamen:
- logo.png
- banner-nl.jpg
- banner-fr.jpg

## Cache
De preview voegt automatisch een tijdelijke cache-buster toe. Daardoor ziet de gebruiker na een wijziging meteen de nieuwste afbeelding.

De effectieve handtekening die naar Outlook wordt gekopieerd gebruikt géén cache-buster maar de vaste URL. Daardoor blijven bestaande handtekeningen verwijzen naar dezelfde bestandsnaam.

## Publiceren
Bij een wijziging:
1. Download het websitepakket vanuit Beheer.
2. Upload de nieuwe index.html naar GitHub.
3. Hebt u een logo of banner aangepast? Upload dan ook het betreffende losse bestand.
