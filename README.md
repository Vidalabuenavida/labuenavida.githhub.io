# La Buena Vida Handtekeninggenerator – GitHub Pages

## Eerste publicatie

1. Maak op GitHub een nieuwe repository aan, bijvoorbeeld:
   `handtekeninggenerator`
2. Upload de volledige inhoud van deze map naar de hoofdmap van de repository:
   - `index.html`
   - `.nojekyll`
   - map `assets`
3. Ga in GitHub naar:
   **Settings > Pages**
4. Kies bij **Build and deployment**:
   **Deploy from a branch**
5. Kies:
   - Branch: `main`
   - Folder: `/ (root)`
6. Bewaar.

Uw URL wordt normaal:
`https://UW-GEBRUIKERSNAAM.github.io/handtekeninggenerator/`

## Logo en banners instellen

Na de eerste publicatie:

1. Open:
   `https://UW-GEBRUIKERSNAAM.github.io/handtekeninggenerator/?beheer=1`
2. Upload:
   - logo
   - banner NL
   - eventueel banner FR
3. Controleer de publieke URL in Beheer.
   Deze wordt op GitHub Pages normaal automatisch ingevuld.
4. Klik op **Websitepakket downloaden**.
5. Pak de ZIP uit.
6. Vervang in uw GitHub repository de bestaande bestanden door de nieuwe:
   - `index.html`
   - `assets/logo.png`
   - `assets/banner-nl.jpg`
   - `assets/banner-fr.jpg` indien gebruikt

De bestandsnamen blijven altijd gelijk. Daardoor blijven bestaande online handtekeningen naar dezelfde URL verwijzen wanneer u later een nieuwe banner publiceert.

## Belangrijk

De gewone online handtekening kan zo automatisch een nieuwe banner tonen omdat de afbeeldings-URL gelijk blijft.

De knop **RDS / Classic Outlook** maakt bewust een versie met lokale afbeeldingen. Die versie verandert niet automatisch mee. Bij een nieuwe banner moet die RDS-handtekening opnieuw geïnstalleerd worden.
